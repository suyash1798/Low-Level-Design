
ParkingLot (Python example)
=============================

What this small demo implements
- Parking spots with three sizes: SMALL, MEDIUM, LARGE
- Vehicles with three types: BIKE, CAR, TRUCK
- Parking and exit flow with simple fare calculation by hours

Run
----
From the repository root run the package entry so Python treats the
`ParkingLot` folder as a package:

	python3 -m ParkingLot.main

This will create example spots and vehicles, allocate spots, and print
the allocation and exit logs.
